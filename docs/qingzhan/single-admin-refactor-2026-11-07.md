# 单管理端二开底座改造（2026-11-07）

## 改造结果

- 从 `a5cfecdf5b5fd4502273664cf0efba89023108e1` 新建改造分支，正式前端由 `playground` 迁到 `apps/admin`（`@qingzhan/admin`）。
- 移出五套其他 UI、mock 后端、上游文档站和失效的上游自动化；保留 Vben workspace 共享包、后端、产品文档站、安全与一致性回归。
- 移除管理端 demos/examples、假统计与通知、未实现的个人设置和注册/扫码入口。登录不预填账号密码，不以视觉滑块冒充验证；保留并适配后端一次性票据开关。
- 新开发 seed 不再创建演示导航；保留原工作台组件路径，避免现有首页字段直接失效。管理路由、权限和数据库迁移历史保留。
- 根命令集中为 dev/dev:server、build:admin/build:server，build 仅覆盖业务应用；修正仓库元数据、编辑器入口和当前中英文文档。
- 移除无用 UI/Nitro 直接依赖与 catalog 条目，重建锁文件。统一 Vue SFC 编译器与 Vue 版本，避免 Vue Router 因 peer 身份不同产生重复类型。
- 前端 Docker 镜像只构建管理端并检查配置产物，Nginx 支持可配置的后端源，代理 `/api` 与 `/uploads`，配置文件不缓存。
- CI 收敛为后端、交付质量、admin 浏览器三项业务检查；新增静态结构契约、实际空表单登录、保留六个真实管理请求与角色跨页回归；将现存管理端单元回归纳入交付任务。

跟踪文件从 2257 个降至约 1460 个，未压缩源码从约 10.89 MiB 降至约 4.5 MiB。这些数字不包含 Git 历史、依赖和构建产物，不代表下载体积或安装体积。

## 验证与限制

本机只执行依赖安装、内部配置包准备与静态检查，没有启动服务、容器或浏览器，没有运行单元/E2E、生产应用构建或压测。

已通过：七个交付类型入口、前端/构建/脚本相关 Oxlint/ESLint、后端改动文件 ESLint、浏览器脚本语法、工作流 YAML、`check:starter` 与 Git 空白检查。正常提交钩子仍启用。

运行回归、生产应用/镜像构建以本次分支对应提交的远程 CI 为准，不复用迁移前 PR #12 的成功证据。正式 HTTPS、容量和恢复验收仍由部署环境完成。

## 升级

参见 [单前端迁移指南](./single-admin-migration.md)。已有数据库不会因目录裁剪而被自动重置或删除菜单；部署方应备份后复核旧演示菜单，保护自己的业务页面和授权。迁移后的公开生产 mode 文件继续被版本控制，本地秘密文件仍忽略。

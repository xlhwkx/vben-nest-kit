# 第十三轮：管理入口与生产交付闭环（2026-11-07）

## 定位与证据限制

本轮本机按用户要求仅审查源码、修改代码与做静态检查，未启动 Nest/Vite、数据库/Redis/容器或浏览器，未运行单元/E2E/压力测试或生产构建。获得提交推送授权后，已通过 PR #12 在 GitHub 的隔离环境执行 CI；远程证据与本机静态检查分别记录，不复用旧轮测试数量作为本轮证据。

目前可称为**待验收的企业二开底座**。投产结论仍依赖对应提交的真实 CI、正式产物预发联调、目标容量与恢复验收。

## 已实现的交付改动

### 1. 明确完整管理入口

- 完整管理前端为 playground：`pnpm dev:admin`、`pnpm build:admin`，开发端口 5555。
- web-antd 保留认证、动态路由、续期与另一套 UI 的接入示例；不宣称包含六个管理页面。
- playground 默认 backend 权限模式，关闭 Nitro mock；两套生产 API 默认 `/api`，构建目标 ES2022。
- 标题和独立缓存命名空间放入已跟踪的 mode 文件，避免改动只停留在被忽略的本机 `.env`。

### 2. 补齐生产管理员的页面路由

原空库 bootstrap 创建了管理权限，却没有对应管理路由。新增共享导航定义与 provision 方法，为选定角色创建 System 根目录及用户/角色/菜单/部门/字典/字典数据六个页面；字典数据页使用 `:code`，在菜单隐藏并指向字典父页。

空库 bootstrap 创建导航并设置首页 `/system/user`；开发 seed 只给 super/admin，普通 user/jack 不获管理路由。已有库新增 `provision:admin-routes`，要求指定活跃、持有全部系统权限的管理员；使用专属导航角色，不扩大共享旧角色的权限。停用、共享、含其他授权的专用角色或菜单名称/路径/组件/拓扑冲突会拒绝。在管理写锁及一个事务中完成导航、关联、首页和审计。

已新增 E2E 断言：选择性授权、重复补齐不改旧菜单、普通角色不获页面、冲突事务回滚与自定义路径冲突。生产镜像 bootstrap 烟测增加导航授权数和首页断言。以上运行验证待执行。

### 3. 配置校验与实际产物一致

新增两套前端专用配置 guard，拒绝 Nitro mock、验证码旁路、上游 mock 主机、凭据 URL、非 HTTP(S) URL、协议相对 URL 及反斜杠等异常 API 地址。错误不打印环境值。

共享配置加载统一委托 Vite 解析器，显式传递实际 mode，使应用配置、构建 guard 和运行时 `_app-config` 的文件优先级、进程环境覆盖及 `${...}` 展开保持一致。新增 mode/进程覆盖/公开前缀/变量展开回归。

新增 `check:delivery:artifacts`，要求两套 dist 各有且只有一份运行时配置，index 实际引用该配置，公开键和值符合约束，API 等于交付预期。它仅解析 JSON 赋值，不执行生成的 JavaScript；默认预期 `/api`，跨域目标通过同一个环境变量传入。

### 4. 本仓库可触发的交付 CI

新增 `.github/workflows/qingzhan-delivery.yml`，对 main 推送/PR 与手工触发有效，无上游仓库名限制。使用 Node24、根冻结锁安装、正常内部包 stub、只读权限和 checkout 不持久化凭据。

质量任务覆盖两套前端及共享包/后端类型、相关 lint、request/utils/Vite 配置回归、两套生产构建与产物检查。浏览器矩阵为两个 UI 各启动可丢弃 PG16/Redis7，生成并遮罩临时秘密，迁移和显式开发 seed，构建后端，运行真实浏览器回归，最后清理本次 Compose 项目。

runner 只启动和停止自己创建的 API/Vite 进程；固定 loopback 端口，已占用时拒绝运行，不接管已有服务。浏览器脚本通过真实 Vite 源模块、Cookie 和 Web Locks 覆盖多标签页续期、切账号后的旧请求/队列、错号 Cookie、退出失败重试、iframe URL 与 sandbox；playground 额外覆盖六个管理页面的真实读请求。

生产构建与源码浏览器回归分别执行。尚未有生产压缩包的浏览器自动化证据，必须另做 HTTPS 预发站验收。

现有后端 CI 去掉 paths 过滤并允许手工触发，避免配置成必需检查后被 paths 跳过而 pending；保留既有后端单元、真实 E2E、镜像烟测。未修改远端分支保护或派发 workflow。

### 5. 修复静态类型与更新文档

- 共享 Vue Router 类型增强改为包自身的类型引用，修复错误 `.d.mts` 路径；utils 测试显式验证索引 fixture 存在。
- 修复 Vite 配置测试的 hook 参数、上下文和 fixture 类型，使配置包可独立检查。
- 根 README 更新为冻结锁安装、显式开发 seed、主前端与安全生产初始化路径；中英架构/贡献及部署入口同步。
- [生产验收指南](./production-acceptance.md)提供已有库升级、同源 Nginx、隔离回归、通过标准与证据表。
